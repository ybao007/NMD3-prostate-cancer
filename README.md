# NMD3 Prostate Cancer Manuscript — Reproducible R Analysis

This repository contains the R analysis and plotting code used to generate the computational results for the NMD3 prostate cancer manuscript.

The main analysis is intentionally maintained as **one sequential R script** because several later figure panels reuse dataset-specific objects generated earlier in the workflow. Run the script from the repository root and from top to bottom for a complete reconstruction.

## Repository contents

```text
NMD3-prostate-cancer/
├── README.md
├── NMD3_manuscript_analysis.R
├── data/
└── results/
```

- `NMD3_manuscript_analysis.R` — complete analysis and plotting workflow.
- `data/` — input data arranged according to the directory structure below.
- `results/` — output tables and figures generated by the script where panel-specific output directories are used.

## Running the analysis

1. Clone or download this repository.
2. Place the required input files under `data/` using the exact directory structure shown below.
3. Open R in the repository root directory.
4. Install the required R/Bioconductor packages if they are not already available.
5. Run `NMD3_manuscript_analysis.R` from top to bottom.

The script uses **relative paths** and does not contain user-specific local file paths.

### Main R packages

The analysis uses packages including:

`DESeq2`, `apeglm`, `limma`, `GEOquery`, `Biobase`, `GSVA`, `clusterProfiler`, `fgsea`, `msigdbr`, `org.Hs.eg.db`, `AnnotationDbi`, `cBioPortalData`, `Seurat`, `survival`, `survminer`, `Hmisc`, `igraph`, `ggraph`, `ggplot2`, `ggrepel`, `ggpubr`, `patchwork`, `pheatmap`, `dplyr`, `tidyr`, `tibble`, `readr`, `readxl`, and `data.table`.

Package-installation commands are intentionally not embedded in the analysis script.

### Notes on cohort counting

- TCGA RNA-seq counts, TCGA patient clinical information, and TCGA survival information are different files/representations of the same **TCGA-PRAD** cohort and are therefore counted once.
- The SU2C expression/clinical files and the processed `ARPCvNEPCvDNPC_revision.RData` object are derived from the same **SU2C/PCF 2019** cohort and are counted once.
- MSKCC expression and clinical files are counted as one **MSKCC** cohort.
- In-house RNA-seq and in-house proteomics are listed separately because they are distinct experimental data modalities.

## Reproducibility notes

- The analysis script is designed to be executed sequentially from the repository root.
- Later figure panels may reuse **protected dataset-specific objects** generated by earlier sections; these objects are named to avoid cross-dataset overwriting.
- Statistical tests, thresholds, gene sets, transformations and plotting parameters are specified directly in the script.
- `stopifnot()` checks are retained to verify expected sample numbers, object structure and data alignment during execution.
- Public-source data should be redistributed only when permitted by the original source and applicable data-use terms.
- Large raw sequencing and proteomics files do not need to be stored directly in this GitHub repository if they are deposited in the appropriate public repository; the manuscript Data Availability statement should provide the corresponding accession(s).
